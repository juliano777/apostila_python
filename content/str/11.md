## Módulo textwrap

O módulo `textwrap` da biblioteca padrão do Python é utilizado para formatar
textos automaticamente.  
Ele é muito útil para quebrar linhas longas, ajustar recuos e melhorar a
legibilidade de mensagens exibidas no terminal ou em arquivos de texto.

```python
# Importando o módulo
import textwrap
```

### wrap()

Quebra um texto em várias linhas respeitando uma largura máxima.
O retorno é uma lista.

```python
# Texto de exemplo
foo = 'Python é uma linguagem extremamente versátil e poderosa.'

# Quebrando o texto em linhas de até 20 caracteres
bar = textwrap.wrap(foo, width=20)

# Exibindo o resultado
print(bar)
```

```
['Python é uma', 'linguagem', 'extremamente', 'versátil e', 'poderosa.']
```

Como o retorno é uma lista, pode-se percorrer cada linha:

```python
# Percorrendo as linhas geradas
for linha in bar:
    print(linha)
```

```
Python é uma
linguagem
extremamente
versátil e
poderosa.
```

### fill()

Funciona de forma semelhante ao `wrap()`, mas retorna uma única *string*
formatada com quebras de linha.

```python
# Texto de exemplo
foo = 'Python é uma linguagem extremamente versátil e poderosa.'

# Formatando o texto
bar = textwrap.fill(foo, width=20)

# Exibindo o resultado
print(bar)
```

```
Python é uma
linguagem
extremamente
versátil e
poderosa.
```

### shorten()

Encurta um texto para um tamanho máximo definido.
Quando necessário, adiciona reticências (`...`) automaticamente.

```python
# Texto original
foo = 'Python é uma linguagem extremamente versátil e poderosa.'

# Reduzindo o texto para 30 caracteres
bar = textwrap.shorten(foo, width=30)

# Exibindo o resultado
print(bar)
```

```
Python é uma linguagem...
```

O parâmetro `placeholder` permite alterar o texto utilizado no final.

```python
# Utilizando outro marcador
bar = textwrap.shorten(
    foo,
    width=30,
    placeholder=' [continua]'
)

# Exibindo o resultado
print(bar)
```

```
Python é uma [continua]
```

### dedent()

Remove recuos comuns de várias linhas de texto.
Muito utilizado em *strings* multilinha.

```python
# Texto com indentação
foo = '''
        PostgreSQL
        Python
        FreeBSD
'''

# Removendo os espaços em comum
bar = textwrap.dedent(foo)

# Exibindo o resultado
print(bar)
```

```
PostgreSQL
Python
FreeBSD
```

Sem o `dedent()`, os espaços iniciais seriam preservados.

### indent()

Adiciona um prefixo ao início de cada linha.

```python
# Texto original
foo = 'Python\nPostgreSQL\nLinux'

# Adicionando indentação
bar = textwrap.indent(foo, prefix='>>> ')

# Exibindo o resultado
print(bar)
```

```
>>> Python
>>> PostgreSQL
>>> Linux
```

O prefixo pode ser qualquer sequência de caracteres.

```python
# Utilizando outro prefixo
bar = textwrap.indent(foo, prefix='* ')

# Exibindo o resultado
print(bar)
```

```
* Python
* PostgreSQL
* Linux
```

### Exemplo prático

O módulo `textwrap` é bastante útil para formatar saídas em terminal.

```python
# Texto longo
foo = (
    'O PostgreSQL é um sistema gerenciador de banco de dados '
    'objeto-relacional extremamente robusto.'
)

# Formatando a saída
print(textwrap.fill(foo, width=40))
```

```
O PostgreSQL é um sistema
gerenciador de banco de dados
objeto-relacional extremamente
robusto.
```

### Considerações finais

O módulo `textwrap` facilita a manipulação e formatação de textos,
principalmente em aplicações de terminal, geração de relatórios e saídas
formatadas.
Entre seus principais recursos estão:

* Quebra automática de linhas;
* Ajuste de largura de texto;
* Remoção de indentação;
* Adição de prefixos;
* Resumo de textos longos.
